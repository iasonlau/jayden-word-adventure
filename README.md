# 字字探險隊

以香港廣東話學習繁體中文的兒童 PWA，包含：

- 「字靈森境」俯視角探索 RPG：三段連貫主線、自然加速移動、伙伴沿路跟隨、九個廣東話詞語挑戰、次序與位置謎題及古門寶藏
- 原創繪本風小狐狸與三種字靈伙伴、手繪村落森林地圖、觸控／鍵盤操作、Web Audio 回饋及 `zh-HK` 廣東話指令
- 原有 50 題能力評估，沿用 `zizi_assessment_v1` 進度
- 說話屋：咪高峰權限、可用時的 `zh-HK` 語音辨認、關鍵詞提示、重試及家長後備評分
- 7 站冒險地圖、每日 5 分鐘任務、星星與錯題複習
- 統一繪本 RPG 風格的學習小屋，以及可自訂字詞／句子、廣東話讀題、手寫或鍵盤作答、自評及錯字重溫的默書工房
- 家長中心、進度備份／還原、自訂學校詞語
- iPhone、iPad、桌面響應式及離線 PWA

## 使用與部署

這是免建置的靜態網站。把根目錄所有檔案部署到 HTTPS 網站即可。GitHub Pages 可直接由 `main` 分支根目錄發布。

iPhone／iPad 請用 Safari 開啟，按「分享」→「加入主畫面」。第一次使用說話屋時允許咪高峰權限。

森境關卡支援觸控十字方向盤四方向移動，以及右側「字光／互動」鍵；桌面亦可用方向鍵、空白鍵及 E 鍵。遊戲會尊重系統「減少動態效果」設定，任務提示亦透過 `aria-live` 提供給輔助技術。

## 語音限制

Web Speech API 在 iOS 的支援與辨認品質並不穩定，尤其是兒童廣東話。程式只把辨認文字用作答案關鍵詞提示；最終口語評分由家長確認，不會聲稱能可靠評估粵語聲調或發音準確度。真正的發音評估需要另設經驗證的後端語音模型、家長同意及錄音私隱政策。
